# Awesome AI GTM [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of open-source repos for building **AI-powered B2B go-to-market**: agent skills, MCP connectors, workflow automation, web research, RevOps data, email and free courses.

GitHub is the best free library on the internet. With an AI agent like Claude Code beside you, almost anything here is a few prompts away from working for your GTM. Every repo on this list is one we use in our own work at [Clarafold](https://clarafold.com) and find genuinely useful. Each entry says what it is and what a GTM team can use it for.

## Claude Code & Agent Skills

- 🟢 [anthropics/skills](https://github.com/anthropics/skills): Anthropic's public Agent Skills repo, with examples and the spec. **GTM use:** read a few, then package one of your own repeatable GTM processes the same way.
- 🟢 [anthropics/claude-code](https://github.com/anthropics/claude-code): agentic tool for your terminal and editor that runs multi-step tasks. **GTM use:** the engine most repos on this list plug into. Install it first.
- 🟢 [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills): marketing skills for CRO, copywriting, SEO, analytics and growth. **GTM use:** copywriting, cold email and page reviews from day one.
- 🟢 [cyberanon1111/clarafold-gtm-skills](https://github.com/cyberanon1111/clarafold-gtm-skills): five B2B GTM workflows as agent skills (ICP research, outbound personalization, LinkedIn content research, lead enrichment, account prioritization). **GTM use:** run Clarafold's own playbooks with your AI.
- 🔵 [hesreallyhim/awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code): hand-picked commands, skills, hooks and workflows for Claude Code. **GTM use:** see how others set up their agents before building your own.
- 🔵 [zubair-trabzada/geo-seo-claude](https://github.com/zubair-trabzada/geo-seo-claude): GEO-first SEO skill with AI citability scoring, crawler access, llms.txt and schema checks. **GTM use:** audit how visible a site is to ChatGPT, Perplexity and Google AI.
- 🟣 [obra/superpowers](https://github.com/obra/superpowers): agentic skills framework for disciplined planning, testing and review. **GTM use:** study how it breaks big tasks into checked steps.
- 🟣 [wshobson/agents](https://github.com/wshobson/agents): plugin marketplace of specialised agents and skills. **GTM use:** pick single-purpose agents instead of writing every one from scratch.

## MCP & Connectors

- 🟢 [modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers): reference Model Context Protocol servers plus a community directory. **GTM use:** learn how an agent talks to files, databases and APIs.
- 🔵 [punkpeye/awesome-mcp-servers](https://github.com/punkpeye/awesome-mcp-servers): large, categorised list of community MCP servers. **GTM use:** check here before writing an integration.
- 🟣 [microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp): MCP server that lets an agent drive a real browser. **GTM use:** check landing pages and collect data from sites with no API.

## Workflow Automation

- 🟢 [n8n-io/n8n](https://github.com/n8n-io/n8n): fair-code workflow automation with native AI nodes. **GTM use:** self-host the glue between CRM, enrichment, email and Slack.
- 🟢 [activepieces/activepieces](https://github.com/activepieces/activepieces): open-source automation with integrations that double as MCP servers. **GTM use:** a friendlier n8n alternative for non-technical teams.
- 🔵 [Zie619/n8n-workflows](https://github.com/Zie619/n8n-workflows): searchable collection of n8n workflow templates. **GTM use:** start from a working template, not a blank canvas.

## Research & Web Data

- 🟣 [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl): turns websites into clean, LLM-ready data. **GTM use:** feed account research, competitor and pricing pages to an agent.
- 🟣 [unclecode/crawl4ai](https://github.com/unclecode/crawl4ai): open-source crawler that outputs clean Markdown. **GTM use:** self-hosted research crawls without per-page fees.
- 🟣 [browser-use/browser-use](https://github.com/browser-use/browser-use): Python library for agents that use a browser like a person. **GTM use:** automate research steps that need logging in and clicking.

## RevOps & Data

- 🟢 [metabase/metabase](https://github.com/metabase/metabase): easy open-source BI and dashboards. **GTM use:** pipeline and funnel dashboards your team actually opens.
- 🟣 [twentyhq/twenty](https://github.com/twentyhq/twenty): open-source, AI-ready CRM alternative to Salesforce. **GTM use:** own your CRM and let agents read and write to it directly.
- 🟣 [PostHog/posthog](https://github.com/PostHog/posthog): product analytics, session replay, flags and experiments. **GTM use:** connect what accounts do in-product to what sales sees.
- 🟣 [airbytehq/airbyte](https://github.com/airbytehq/airbyte): open-source data pipelines into warehouses and agents. **GTM use:** one place for CRM, ads and email data so scoring uses the same numbers.

## Email & Outbound

- 🟣 [knadh/listmonk](https://github.com/knadh/listmonk): fast, self-hosted newsletter and mailing-list manager. **GTM use:** run a newsletter without paying per subscriber.
- 🟣 [resend/react-email](https://github.com/resend/react-email): email templates as React components. **GTM use:** let an agent write and change lifecycle templates as code.
- 🟣 [reacherhq/check-if-email-exists](https://github.com/reacherhq/check-if-email-exists): verify an address exists without sending. **GTM use:** clean lists before a cold campaign to protect sender reputation.
- 🟣 [mautic/mautic](https://github.com/mautic/mautic): open-source marketing automation with segments, campaigns and scoring. **GTM use:** a self-hosted alternative for nurture programmes.

## Learn

- 🟢 [anthropics/prompt-eng-interactive-tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial): Anthropic's step-by-step prompt engineering tutorial. **GTM use:** the best few hours to spend before building anything with AI.
- 🟢 [microsoft/ai-agents-for-beginners](https://github.com/microsoft/ai-agents-for-beginners): free 18-lesson course on AI agents. **GTM use:** learn what agents can and can't do before trusting one with pipeline.
- 🟢 [microsoft/generative-ai-for-beginners](https://github.com/microsoft/generative-ai-for-beginners): free 21-lesson course on generative AI apps. **GTM use:** a structured path to your first AI-powered tool.
- 🟣 [anthropics/claude-cookbooks](https://github.com/anthropics/claude-cookbooks): notebooks and recipes for building with Claude. **GTM use:** copy working patterns for extraction, classification and agents.
- 🔵 [dair-ai/Prompt-Engineering-Guide](https://github.com/dair-ai/Prompt-Engineering-Guide): guides on prompting, context engineering, RAG and agents. **GTM use:** a reference for when a prompt isn't behaving.
- 🔵 [f/prompts.chat](https://github.com/f/prompts.chat): open-source community prompt library. **GTM use:** see how others frame roles and tasks.

## How to use this list

You don't need to be a developer. Open Claude Code (or your agent of choice), point it at a repo and ask in plain English:

> "Read the README of github.com/coreyhaines31/marketingskills, install it, and use it to review our homepage copy."

Every repo belongs to its own authors and has its own license. Read it before using one commercially.
